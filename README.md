# TODO-приложение на Go

Простое веб-приложение для управления задачами с поддержкой повторений.  
Позволяет добавлять, редактировать, удалять и отмечать задачи как выполненные.  
Поддерживает одноразовые и периодические задачи (ежедневные, ежегодные).

## Описание проекта

Проект реализует бэкенд для TODO-приложения на языке Go.  
Фронтенд обслуживается статически, бэкенд предоставляет REST API для работы с задачами.  
Данные хранятся в SQLite-базе `scheduler.db`.

### Основные возможности:
- Добавление задач с датой и правилом повторения.
- Просмотр списка ближайших задач.
- Редактирование и удаление задач.
- Отметка задач как выполненных с автоматическим переносом по правилу.
- Поддержка правил повторения: `d <число>`, `y`.

## Задания со звёздочкой

Выполненных заданий повышенной сложности нет.

## Запуск проекта локально

Запустите сервер: 

go run main.go
 
Откройте в браузере: 
http://localhost:7540

Сервер автоматически создаст файл scheduler.db и таблицу scheduler, если их нет. 

## Запуск тестов 

go test ./tests

## Примечания

Все даты хранятся в формате YYYYMMDD (Go: 20060102).
При добавлении задачи с date=today устанавливается текущая дата.
При выполнении периодической задачи дата переносится по правилу через NextDate().
Одноразовые задачи удаляются при отметке как выполненные.
